# 카페 한국어 말하기 확인 PoC (Whisper)

외국인 학습자가 카페 주문 문장을 말하면, Whisper가 인식해 정답과 비교합니다.

## 모델 선정 이유
- Whisper: 한국어 지원, 오픈소스라 Colab에서 무료 실행
- 브라우저 음성인식: 브라우저마다 동작이 달라 재현이 어려움
- 유료 API: 키·비용이 필요해 PoC 단계에 부적합
- small과 medium을 비교한 결과는 검증결과.md 참고

## 실행 방법
1. Colab에서 `cafe_stt.ipynb` 열기
2. 런타임 → 런타임 유형 변경 → T4 GPU
3. 런타임 → 모두 실행
4. '파일 선택'이 뜨면 `audio/` 폴더의 녹음 파일 업로드
